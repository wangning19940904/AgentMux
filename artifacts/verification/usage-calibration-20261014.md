## 已修复的问题

1. **Codex 双入口重复（P1）**：三个会话共 180 对实时记录和 rollout 记录，input/output/cache 各分项精确相等，相差最多 39.70 秒。移除报表中的重复项后减少 16,708,427 Token 和 $8.8506392。保留账本，按同机器、会话、模型及全部 Token 分项，在 60 秒内做一对一归并；未匹配记录、独立重试和尾部记录继续保留。
2. **Cursor 双入口重复（P1）**：一条 stop hook 和 dashboard 对应同一次请求。hook 的 input 为 30,134，等于 dashboard 非缓存输入 4 + cache-read 9,328 + cache-write 20,802，既重复采集又包含缓存。报表保留 dashboard 的 30,152 Token 和记录金额，排除得到交叉佐证的 hook，减少 60,282 Token 和 $0.2267716。未匹配 hook 不猜测输入口径。
3. **长上下文价格缺失（P1）**：价格表有 above_272k_tokens 档位，原解析器忽略。120 条本机和 152 条远程 GPT-6 Astra 请求超过 272K 输入，需分别补计 $54.158784 与 $76.519751。新实现读取标准上下文档位，阈值使用非缓存输入 + 缓存读取 + 缓存写入；输出不参与阈值，恰好等于阈值不升级。
4. **用量刷新和跨日口径（P1）**：原页面只刷新健康数据却更新“上次更新”时间。现每 30 秒及恢复前台刷新用量，时间只绑定成功收到的用量快照，跨午夜重算日期范围。
