# SSH 自动重试优化

本记录补充同日的 SSH/CLI 根因修复记录。

## 行为

- 连接建立和只读健康检查最多尝试 3 轮；默认重试退避约 200/400 ms，带随机抖动。
- 同一机器共享握手等待与失败冷却，持续连接失败时冷却最长 2 秒，成功后重置。
- 每轮保留后续尝试的时间，遵守请求总截止时间；连接排队、退避和原生 SSH 握手均可取消。
- 主机密钥、鉴权和权限错误不盲目重试。原生客户端不支持 GSSAPI 时，按系统 SSH 的实际失败原因判断。
- 仅重试发送 HTTP 数据之前的连接建立；只读健康检查可重试临时不可用响应。不会因响应丢失而重放 HTTP 写请求。
- Fleet、直接代理和渠道连接传递原始请求上下文，避免 HTTP 库分离拨号上下文后丢失总超时。
